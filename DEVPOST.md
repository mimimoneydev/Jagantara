# Jagantara — Devpost description

Jagantara turns a family place, a time window, an attributed memory, and a few cultural interests into an evidence-aware journey. Its agent retrieves historical sources, resolves selected interests to Qloo entity IDs, queries cross-domain Insights, checks every claim, and composes a map-and-timeline experience where provenance is never hidden.

The key interaction is Taste Swap: judges can begin with a Native American, Irish, Italian, or African American sample, then switch from a rhythm-led profile to a page-and-screen profile. Every sample uses a disclosed fictional memory and avoids claiming ancestry. The selected historical timeline does not move; only live Qloo discoveries across music, books, film, and destinations change. A “why this appeared” drawer shows the resolved Qloo signals and explains that affinity is aggregate cultural context—not ancestry, historical proof, or a prediction about the user.

Every item is typed as source-backed history, family testimony, Qloo taste connection, or creative reconstruction. Unsupported historical claims are rejected. Qloo failures are shown honestly and never replaced with made-up recommendations. The account-free sample memory is explicitly fictional, the Qloo key stays server-side, and the complete workflow is test-covered and open source under MIT.
